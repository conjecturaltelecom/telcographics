# Start Here

Welcome to the Telco Graphics Repository.

This repository is used to recreate, preserve, and organize telecommunications-related graphics, logos, decals, signage, and other artwork.

## Workflow

### 1. Check the `INCOMING` Folder

The `INCOMING` folder contains source images, scans, photographs, or reference materials that need to be recreated or cleaned up.

If you're looking for something to work on, start here.

### 2. Recreate the Artwork

Please recreate the graphic as accurately as possible from the provided reference material.

When possible:

* Use vector graphics for scalability.
* Preserve original colors, proportions, and typography.
* Document any assumptions or corrections made during the recreation process.

### 3. Export Your Work

All completed artwork should be provided in the following formats:

* **SVG** (editable vector source)
* **PNG** (transparent background preferred)

These formats help ensure the artwork is both editable and easily viewable.

### 4. Submit to the `COMPLETED` Folder

Once finished, place the completed files in the `COMPLETED` folder.

Recommended file structure:

```
COMPLETED/
├── Company_Name_Logo.svg
├── Company_Name_Logo.png
```

## Naming Conventions

Use descriptive filenames whenever possible.

Examples:

* `AT&T_Long_Lines_Logo.svg`
* `Bell_System_Sign.png`
* `Independent_Telephone_Co_Decal.svg`

## Quality Standards

Before submitting:

* Verify spelling and typography.
* Check alignment and proportions.
* Ensure SVG files are clean and editable.
* Confirm PNG exports are clear and high resolution.

## Questions?

If you're unsure about a graphic, missing source material, or need clarification, open an issue or discussion before starting work.

Thank you for helping preserve telecommunications history.
